# Fonts

**Newsreader** (variable: weight 200–800 + optical size, latin subset,
normal + italic) — designed by Production Type for Google Fonts.

Copyright 2017 The Newsreader Project Authors
(https://github.com/productiontype/Newsreader)

Licensed under the SIL Open Font License, Version 1.1:
https://openfontlicense.org

Self-hosted via `next/font/local` (see `app/layout.tsx`) so the record
renders in the same serif on every platform, offline included — the
previous stack ("Iowan Old Style", Palatino…) only existed on Apple
devices.
